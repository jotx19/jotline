# Changelog

All notable changes to this project are documented here. Sections for new releases are generated by [release-please](docs/RELEASING.md) from Conventional Commit pull request titles.

## 0.3.0

First release as **jotline** (previously `local-cli` / `local-codex`).

### Breaking changes

- The binary is `jotline`, the library crate is `jotline-core` (`jotline_core`), and the repository is a Cargo workspace under `crates/`.
- Workspace state moved from `.local_codex/` to `.jotline/`, and plugins receive `JOTLINE_WORKSPACE` instead of `LOCAL_CODEX_WORKSPACE`. Move existing files with `mv .local_codex .jotline`.
- `replace_in_file` is replaced by `edit_file`, which requires a unique match unless `replace_all` is set. `structured_patch` `replace_text` keeps the old replace-all behavior.
- Removed the `open_calculator` and `model_routing` tools and the unused `--image-model` flag.
- `--no-tool-logs` is now `--quiet` (the old flag still works). `--text-model` is now `--model` (the old flag still works).
- Session files are written as version 4; version 3 files still load.

### Features

- Intent routing: every request is classified (feature, bugfix, refactor, test, review, docs, question, ops, general) and receives a matching playbook. `/intent <request>` shows the classification.
- Verification gate: after file changes, a `final` answer is accepted only once a command has run, or after one reminder.
- Markdown rules: built-in coding-principles, code-generation, testing, and security rules, plus project rules from `JOTLINE.md`, `AGENTS.md`, and `.jotline/rules/*.md`. New `/rules` commands and a `rules_add` tool for "from now on" requests.
- New tools: `search_files` (regex content search), `find_files` (glob), and `edit_file`.
- Typed, lenient action parsing: `<think>` blocks, fenced and embedded JSON, common key aliases, inferred action types, and specific correction messages.
- Context window trimming with `--max-history` that always keeps the current request.
- Environment variables `JOTLINE_MODEL`, `JOTLINE_PROVIDER`, `JOTLINE_ENDPOINT`, `JOTLINE_PLANNER_MODEL`, `JOTLINE_CODER_MODEL`.
- Clear guidance when an Ollama model is not installed.
- `--prompt` exits with status 1 when the task does not finish with a handoff.

### Bug fixes

- Commands that print more than the OS pipe buffer no longer hang until the timeout.
- A timeout now kills the command's whole process group instead of leaving child processes running.
- Truncating long tool output no longer panics on multi-byte characters.
- Concurrent `memory_set` calls in `parallel_tools` no longer lose writes, and a corrupt memory file is reported instead of overwritten.
- `apply_patch` works in a workspace nested inside a larger repository.
- Python symbol ranges include decorators and support `async def`.
- Tool specs render in a stable order.
